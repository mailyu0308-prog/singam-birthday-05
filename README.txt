SINGAM BIRTHDAY SURPRISE WEBSITE

HOW TO OPEN IN VS CODE
1. Extract the ZIP file.
2. Open VS Code.
3. Choose File > Open Folder.
4. Select the extracted "singam-birthday" folder.
5. Open Terminal > New Terminal.
6. Run these commands:

   npm install
   npm run dev

7. Open the localhost link shown in the terminal.

SECRET PASSCODE
The default passcode is: 05122026
To change it, open src/App.jsx and edit SECRET_PASSCODE near the top.

CUSTOMIZE THE LETTER
Open src/App.jsx and edit the words inside the "inner-letter" section.
The sign-off currently says "Your Mayil 🦚".

NOTES
- This is a React + Vite project.
- Internet is needed once for npm install and to load the Google Fonts.
- The memory cards are placeholders. You can add real photos/videos later.
